# Portfolio Summary

## Project
Saudi Public Sector AI Governance Lab

## What I built
A technical prototype showing how AI governance can be operationalised for a simulated Saudi public-sector environment. The repository includes:

- AI use-case intake
- AI inventory
- Illustrative risk assessment engine
- RACI accountability matrix
- Governance lifecycle gates
- AI control library and evidence requirements
- Governance dashboard
- Automated tests and GitHub Actions CI

## Interview description
> I built a self-directed AI governance case study to translate governance frameworks into an operating model. I designed the AI inventory, risk screening, RACI accountability model, lifecycle gates, control library and monitoring dashboard. I used the NIST AI RMF structure as a reference and tailored the simulated scenario to a Saudi public-sector context. The project is a portfolio prototype, not a client implementation.

## Important limitation
The included risk-scoring heuristic is illustrative and educational. It is not an official NIST, SDAIA or legal risk classification method.
